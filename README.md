# ShayanAI Backend

Node.js backend for ShayanAI chatbot to book Google Calendar events via webhook.

## Setup
1. Set environment variables:
   - CLIENT_ID
   - CLIENT_SECRET
   - REDIRECT_URI
2. Install dependencies: `npm install`
3. Run: `node index.js`
4. Webhook endpoint: `/book`
